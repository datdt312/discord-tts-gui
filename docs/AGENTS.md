# Documentation scope

Apply the [root contract](../AGENTS.md). This directory is the maintained
knowledge map; keep docs/README.md and task-specific links navigable.

- Record current behavior from code/tests; keep historical notes under plans/archive/.
- Use repository-relative links and generic paths; no machine-specific checkout locations.
- Keep native/hardware validation gaps explicit. Do not claim a release or CI success without evidence.
- Add lasting tradeoffs under decisions/; do not turn transcripts into operating instructions.
- Run `python tools/check_repo.py` after moving or linking documents.
