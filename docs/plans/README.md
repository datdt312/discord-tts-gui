# Execution records

Use a plan for work with meaningful dependent steps, risky boundaries or a
multi-session handoff. Small documentation/typo changes do not need one.

- `active/`: current goals, decisions, verification and next steps.
- `archive/`: completed or historical implementation records. These describe
  their original environment and may contain outdated commands or test counts.

Use a date and topic in the filename. A useful record contains scope, acceptance
behavior, decisions, ordered steps, evidence and remaining gaps. Move a completed
record to the archive and link to maintained docs for lasting behavior.

The [change workflow](../harness/workflow.md) remains the operating procedure;
old plans do not override it or the user's current task.
